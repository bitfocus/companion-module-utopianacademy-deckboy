# companion-module-utopianacademy-deckboy

[Bitfocus Companion](https://bitfocus.io/companion) module for
[Deckboy](https://github.com/Utopian-Academy/Deckboy), a free, open-source cue deck for theatre,
live events and broadcast.

Transport, cue tally, output health and countdowns on your Stream Deck. See
[HELP.md](./companion/HELP.md) for setup, actions, feedbacks, variables and presets.

## Development

```
yarn install
yarn test      # protocol and wiring tests, no Companion needed
yarn package   # builds the module package
```

Needs Node 22.20 or newer.
